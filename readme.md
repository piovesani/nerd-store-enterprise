🏪 NerdStore Enterprise

Aplicação corporativa construída com C# e .NET para demonstração de padrões modernos de arquitetura, escalabilidade e boas práticas.

📌 Sobre o Projeto

O NerdStore Enterprise é uma aplicação empresarial voltada para estudos de arquitetura de software, boas práticas de desenvolvimento e padrões amplamente utilizados em projetos de grande escala.
O objetivo principal é criar uma base sólida para aplicações complexas, utilizando conceitos como:

Clean Architecture / DDD (Domain-Driven Design)

CQRS

Event Sourcing (opcional)

Microservices (opcional)

SOLID

Boas práticas de testes

Mesmo sendo um projeto de estudo, o foco é desenvolver algo próximo de um cenário real de mercado.

🚀 Tecnologias Utilizadas

.NET 8+

C#

ASP.NET Core

Entity Framework Core

SQL Server / MySQL / PostgreSQL (dependendo da sua escolha)

MediatR (para CQRS)

AutoMapper

Swagger / OpenAPI

Docker (opcional)

🧱 Arquitetura

O projeto segue princípios modernos de arquitetura, como:

🟦 Domain-Driven Design (DDD)

Camada de Domain

Camada de Application

Camada de Infrastructure

Camada de API

🔀 CQRS (Command Query Responsibility Segregation)

Separação clara entre consultas e comandos.

📡 Eventos e Mensageria (caso implementado)

Integração com RabbitMQ, Kafka ou equivalente.
